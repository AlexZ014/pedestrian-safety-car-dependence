## Overview
This project analyzes how car dependence relates to pedestrian safety across the United States. Using publicly available transportation and census data, I cleaned and merged multiple datasets in Excel to examine whether higher reliance on driving correlates with elevated pedestrian fatality rates.

The analysis focuses on state-level and regional patterns, highlighting how mobility behavior (driving vs walking) aligns with pedestrian risk outcomes.

## Dashboard
The Tableau dashboard can be viewed at https://public.tableau.com/app/profile/alex1249/viz/PedestrianSafetyDashboard/Dashboard1

## Data Sources
- Fatality Analysis Reporting System (FARS)
- Governors Highway Safety Association (GHSA)
- American Community Survey (ACS) Mode Share data

## Methods
- Cleaned and standardized datasets in Excel
- Merged sources using XLOOKUP and calculated fields
- Created a custom **Car Dependence Ratio (Drive % ÷ Walk %)**
- Designed Tableau visualizations to communicate geographic and behavioral patterns

## Files
- `/data/pedestrian_safety_cleaned.xlsx` — cleaned and merged analysis dataset
- `/tableau/pedestrian_safety_dashboard.twbx` — Tableau dashboard file

## Key Insight
Regions with higher car dependence tend to experience higher pedestrian fatality rates, underscoring the safety risks associated with car-centric transportation systems.
